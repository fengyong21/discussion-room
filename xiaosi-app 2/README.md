# 🐾 小司 - 桌面宠物

一个基于 Electron 的独立桌面宠物应用。小司会在你的屏幕上自由活动，追着你的鼠标跑，偶尔跟你聊天~

## 📦 安装与运行

### 前置要求

- **Node.js** (v16 或更高版本)
  - 如果没装，去 https://nodejs.org 下载安装

### 步骤

1. 打开终端（Terminal）
2. 进入项目文件夹：
   ```bash
   cd xiaosi-app
   ```
3. 安装依赖：
   ```bash
   npm install
   ```
4. 启动应用：
   ```bash
   npm start
   ```

### 打包成 .app（可选）

```bash
npm run build
```

打包后会在 `dist` 文件夹生成 Mac 应用，可以直接拖到"应用程序"文件夹。

## 🎮 操作方式

| 操作 | 效果 |
|------|------|
| **点击** 小司 | 随机互动（跳跃、说话等） |
| **双击** 小司 | 切换睡觉/醒来 |
| **拖拽** 小司 | 抱到任意位置 |
| **鼠标移动** | 小司偶尔会追着鼠标跑 |
| **右键托盘图标** | 打开菜单（打招呼、睡觉、状态、退出） |

## ⚙️ 特性

- ✅ 透明无边框窗口，宠物浮在桌面最上层
- ✅ 满屏自由活动，追鼠标跑
- ✅ 眼睛跟随鼠标转动
- ✅ 自动眨眼、走路、跳跃动画
- ✅ 情绪系统（开心/普通/低落）
- ✅ 闲置时自动闲逛，长时间不理会自动睡觉
- ✅ 定期主动说话
- ✅ 系统托盘图标 + 右键菜单
- ✅ Dock 栏不显示（后台运行）
